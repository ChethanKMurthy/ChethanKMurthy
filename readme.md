### Recent work

**[Veridion](https://github.com/ChethanKMurthy/veridion)** · [live](https://veridion-nine.vercel.app)\
Reads corporate disclosures, tests them against the reporting standards they cite, and links every finding to the passage it came from. Flags disclosure gaps and benchmarks against peers.\
<sub>Python · FastAPI · Next.js · PostgreSQL</sub>

**[ChangeGuard](https://github.com/ChethanKMurthy/changeguard)** · [live](https://changeguard-navy.vercel.app)\
Risk analysis for code changes. Rebuilds both revisions, follows every caller, lints only what the change introduced and measures test coverage of the changed lines. Submitted code is never executed.\
<sub>Python · Next.js · static analysis</sub>

**[Sahayak](https://github.com/ChethanKMurthy/Sahayak)**\
Voice-first assistant that turns a citizen's documents into a filled, submittable government application in seven Indian languages. Eligibility is decided by a deterministic rules engine, not the LLM, and Aadhaar numbers are masked on-device and never stored.\
<sub>Flutter · Next.js · FastAPI · Groq</sub>

**[Meridian](https://github.com/ChethanKMurthy/Meridian)** · [live](https://meridian-eight-cyan.vercel.app)\
Decision engine for creator marketing. Takes a product, budget and revenue target, picks the creators most likely to hit it, and measures actual returns afterward.\
<sub>TypeScript · Next.js · Drizzle</sub>

**[CTG Terminal](https://github.com/ChethanKMurthy/CTGTerminal)**\
Multi-agent research platform for Indian markets: real-time data pipelines, an options and Greeks engine, VaR and stress testing, and an evaluation loop that scores agent signals by information coefficient.\
<sub>Python · FastAPI · DuckDB</sub>

**[AgentESG](https://github.com/ChethanKMurthy/AgentESG)** · [live](https://agent-esg.vercel.app)\
Agentic RAG system for ESG gap analysis against CSRD and BRSR, running on local Llama 3.2 with a verification step that rejects unsupported claims.\
<sub>Python · hybrid retrieval · Llama 3.2</sub>

**[llm-gateway](https://github.com/ChethanKMurthy/llm-gateway)**\
Control plane for LLM calls with semantic caching, model routing, cost limits and a request dashboard.\
<sub>Python · FastAPI</sub>
